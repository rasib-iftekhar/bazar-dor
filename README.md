# বাজার দর | Bazar Dor

## Description

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দাম, বাজারভিত্তিক মূল্য এবং দৈনিক পরিবর্তন সহজে দেখার একটি responsive web app।

## Technologies

- Next.js 16 App Router
- React 19 and TypeScript
- Tailwind CSS 4
- Better Auth
- MongoDB
- React Hot Toast

## Features

- চাল, ডাল, তেল, সবজি, মাছ, মাংসসহ নিত্যপ্রয়োজনীয় পণ্যের দাম ও একক
- দাম বাড়া ও কমা পণ্যের আলাদা তালিকা
- ক্যাটাগরি অনুযায়ী পণ্য দেখা এবং দাম অনুসারে sort
- পণ্যের সর্বনিম্ন, সর্বোচ্চ ও গড় দামসহ বাজারভিত্তিক তথ্য
- Animated market price ticker
- Email/password, Google ও GitHub sign-in
- Profile দেখা এবং নাম update
- Responsive layout, loading skeleton ও toast notifications
